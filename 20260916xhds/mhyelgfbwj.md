# 流行性感冒

> 更新时间：2026-09-16 (UTC+8)

流行性感冒

一、什么是流行性感冒

　　流行性感冒是由流感病毒引起的急性呼吸道传染病。病原体有甲、乙、丙、丁四型，据世界卫生组织报告，每年流感季节性流行在全球可导致300万-500万重症病例，29万-65万人死亡，流感相关住院和死亡主要发生在65岁及以上老人，5岁以下（尤其是2岁以下）儿童，孕妇以及具有慢性基础疾病的患者。传染性强，易造成暴发性流行。

二、临床表现

　　感染的临床表现可能因病毒种类或亚型而有所不同。

　　主要临床表现为：发热、头痛、浑身酸疼无力、怕冷、多伴有呼吸系统的症状，比如流鼻涕和干咳，发热可达39-40摄氏度。

　　流感也可能引起腹泻和呕吐。流感还能加重潜在的疾病（如心肺疾患）或者引起继发细菌性肺炎或原发流感病毒性肺炎，老年人以及患有各种慢性病或者体质虚弱者患流感后容易出现严重并发症。

三、传染源

　　流感病人和隐性感染者是主要的传染源，一般感染者在发病前24-48小时前即可排出病毒，排毒量在感染后0.5-1天显著增加，发病后24小时内达到高峰。

四、传播途径

　　主要通过呼吸道分泌物飞沫传播，也可通过口腔、鼻腔、眼睛等粘膜直接或间接接触传播，接触被污染的物品也可通过上述途径感染。

五、易感人群

　　普遍易感，病后有一定的免疫力。

六、预防措施

　　流感疫苗是预防流感安全有效的方法，对某些容易因流感而出现并发症的人尤为有效。此外，还可以采取以下预防措施：

　　1.保持良好的个人及环境卫生。

　　2.勤洗手,使用肥皂或洗手液用流动水洗手,不用污浊的毛巾擦手。双手接触呼吸道分泌物后 ( 如打喷嚏后 ) 应立即洗手。

　　3.大量喝水。大量的水可以将病毒从你身上冲走，并防止脱水症的发生，而脱水症则是感冒的并发症之一。

　　4.打喷嚏或咳嗽时应用手帕或纸巾掩住口鼻, 避免飞沫污染他人。流感患者在家或外出时佩戴口罩, 以免传染他人。

　　5.均衡饮食，多吃维生素E和维生素C，适量运动、充足休息, 避免过度疲劳。

　　6.每天开窗通风数次（冬天要避免穿堂风）,保持室内空气新鲜。

　　7.在流感高发期, 尽量不到人多拥挤、空气污浊的场所。
